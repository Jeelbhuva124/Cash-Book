1. PROJECT INTRO (30-SECOND PITCH):
"Cash-Book is a full-stack MERN financial bookkeeping web application. It features
two isolated modules: a User Dashboard (multi-cashbook, income/expense, party
debtor/creditor with auto-interest, EMI alerts, and PDF exports) and an Admin
Panel (system telemetry, user suspension/activation, and soft-delete recovery)."

--------------------------------------------------------------------------------

   -> 3-Tier MERN stack: User/Admin Frontend -> Express.js API -> MongoDB DB.

3. USER SIDE VS ADMIN SIDE (CORE DIFFERENCE):
--------------------------------------------------------------------------------
- USER: Manages own cashbooks, records income/expense, tracks udhar/EMI & reports.
- ADMIN: Platform governance, suspends abusive users, audits & restores deleted data.

--------------------------------------------------------------------------------
4. TOP 3 VIVA QUESTIONS & INSTANT ANSWERS:
--------------------------------------------------------------------------------
Q1: Why MongoDB instead of SQL/MySQL?
Ans: "Financial entries have flexible schemas (interest rates, receipts, EMI data).
     MongoDB handles dynamic JSON documents and high-speed write performance."

Q2: What is the Soft-Delete Pattern?
Ans: "When a user deletes a transaction, it is not erased. It sets is_deleted: true.
     It disappears from the user ledger but remains in DB for Admin recovery."

Q3: How does collaborative book sharing work?
Ans: "Owner sends an email invite with roles (Viewer/Editor/Admin). When accepted,
     the cashbook's chalan_id is shared and Socket.IO syncs live updates."
