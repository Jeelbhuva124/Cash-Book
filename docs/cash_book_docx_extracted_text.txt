P36: 1. Introduction of Project
P37: It aims to simplify personal and small business finance management by offering a fast, convenient, and accessible way to track income, expenses, and debts.
P38: The platform eliminates the limitations of traditional paper ledgers, such as data loss, manual calculation errors, and restricted physical access.
P39: It offers essential financial management features including: 
P40: User registration & secure authentication
P41: Daily transaction tracking (Income/Expense) categorized dynamically
P42: Party Ledger (Udhaar Book) for tracking debts and credits
P43: EMI & Subscription tracking with calendar views
P44: Receipts Vault for securely storing bill images
P45: Advanced analytics and summary reports
P46: Shared cashbooks through user invitations
P47: For admins, the system includes: 
P48: System analytics and user metrics
P49: Transaction and cashbook oversight
P50: Platform setting configurations
P51: Cash-Book acts as a digital companion, allowing users to make informed financial decisions through clear insights and organized records.
P52: The project uses modern web technologies: 
P53: Frontend: React (Vite)
P54: Backend: Node.js (Express)
P55: Database: MongoDB (Mongoose)
P56: It serves as a real-world implementation of an end-to-end financial SaaS solution.

P60: 3. Technology Study
P61: ❖ React :
P62: React was first developed by Jordan Walke at Facebook in 2011.
P63: React is a JavaScript library used for building user interfaces (UI), especially single-page applications (SPA).
P64: React uses a component-based architecture, where the UI is divided into reusable pieces called components.
P65: React uses a Virtual DOM to efficiently update only the parts of the page that change, improving performance.
P66: Vite is used as the build tool, providing a faster and leaner development experience for modern web projects.
P67: ❖ HTML & Tailwind CSS :
P68: First developed by Tim Berners-Lee in 1990, HTML is short for Hypertext Markup Language.
P69: HTML is used to create electronic documents (called pages) that are displayed on the World Wide Web. 
P70: Tailwind CSS is a utility-first CSS framework used in this project to rapidly build custom user interfaces without leaving the HTML/JSX.
P71: ❖ JavaScript :
P72: JavaScript is a dynamic computer programming language.
P73: It is lightweight and most commonly used as a part of web pages.
P74: JavaScript allows client-side scripts to interact with the user and fetch dynamic data asynchronously. 
P75: ❖ Node.js & Express.js :
P76: Node.js was developed by Ryan Dahl in 2009.
P77: It allows running JavaScript outside the browser (on the server side), using the V8 JavaScript engine. 
P78: Express.js is a minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications.
P79: It is used in this project to create RESTful APIs to handle frontend requests securely.
P80: ❖ MongoDB :
P81: MongoDB was first released in 2009 by MongoDB Inc.
P82: MongoDB is an open-source NoSQL database.
P83: It stores data in flexible, JSON-like documents instead of tables, making it perfect for dynamic data models.
P84: MongoDB is schema-less by nature, though Mongoose is used in this project to enforce structured schemas. 
P85: It is designed for high performance, scalability, and flexibility.
